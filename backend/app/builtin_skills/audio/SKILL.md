# 对白、配音与音乐

区分对白、旁白、环境声、音效与音乐。配音文本明确说话者、情绪和停顿，保留人名及专有名词的读法要求。语音请求的 input 保留待朗读正文，表演指导使用服务支持的独立字段。

按镜头或场景给出入点、出点、持续帧数和角色。背景音乐说明节奏、音色、能量变化及对白让位位置。仅使用具备授权的声音与素材。

音轨编排检查静音、截断、叠加与增益，字幕与实际语句相配。确定性检查报告时间与素材事实，听感和可懂度由试听确认。
