# 成片交付

核对工程画幅、分辨率、帧率、总帧数、音频格式及字幕要求。确认主轨中的每个镜头已有当前有效的选中素材，检查待审片项和显式接受的限制。

渲染以最新工程修订为输入。交付后检查文件存在、编码、尺寸、帧率和时长，并保留素材哈希与生成来源。工程包包含媒体、参考关系和时间轴，导出内容按实际格式校验。

演示媒体保留 DEMO/MOCK 标识。把尚需真实服务或人工试听观看的项目列为待验收项。只将检查中实际得到的证据作为交付状态依据。
