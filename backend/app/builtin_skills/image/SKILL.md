# 图像与视觉

将主体身份、动作或姿态、场景、构图、光线和材质分别写清。使用工程风格设定约束色调和视觉语汇，跨镜头复用角色特征与关键道具描述。

首帧或尾帧参考需要匹配后续运动的起始或结束状态。提供图像生成描述时保留镜头景别与画幅要求，结合服务实际支持的参考图能力。

比较候选时分别检查身份一致性、空间布局、手部与道具、文字内容和参考用途。把图像用于镜头输入前预览用途及影响，保留来源和授权信息。
