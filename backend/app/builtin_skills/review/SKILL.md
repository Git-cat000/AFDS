# 审片

将媒体完整性、镜头意图、角色动作、连续性和审美判断分别提出证据。每个问题指向镜头、素材版本与可观察的帧或时间位置，并标注严重程度和修正建议。

比较目标镜头与相邻镜头的角色、服装、持物、方向和动作状态。对采样未覆盖的时间段说明证据范围，避免将少量关键帧结论扩展到整段视频。

确定性媒体检查、模型视觉判断和人工评价保留各自来源。提出局部修正时尊重锁定与批准状态。当前素材更换后，将旧报告标为来源已变化。
