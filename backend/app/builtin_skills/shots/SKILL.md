# 镜头设计

为每个镜头明确观看对象、叙事信息和情绪变化。选择景别时说明主体与环境的关系，优先使用工程支持的 wide、medium、close_up、detail。

运镜描述包含起点、运动方向和结束构图。单个短镜头控制主体动作数量，避免把多个场景或无法同时成立的机位写进一次生成。对话镜头保留视线和动作轴线，插入镜头说明与主动作的关联。

时长使用整数帧。参考图、首帧图、尾帧图各自承担明确作用。提出修改时保留镜头 ID 和未指定的字段，向作者展示受影响镜头。
