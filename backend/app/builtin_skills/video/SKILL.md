# 视频生成

从镜头输入状态开始，按发生顺序描述主体动作、摄影机运动和结束状态。对于短镜头，优先使用一个主要动作与一种清晰运镜。

保留角色身份、服装、持物、空间方向和风格约束。首尾帧条件按服务已声明的映射使用，时长和画幅服从工程参数及接口能力。

修改已生成镜头时，先指出需要改善的具体问题，再保留可用部分的描述与参考。输出生成意图与所用技能来源。真实模型质量由候选比较和审片确认，Mock 输出维持可见演示标识。
