# 模型连接与项目路由

在“模型与工具”配置 LLM、视频、图像、语音合成或转写的 URL、Key 和模型名。高级选项提供协议、超时、能力和单次预估费用。服务须满足适配器契约；URL 不会自动适配任意协议。ComfyUI 使用工作流映射。

原有连接迁移为 default-llm、default-video 等候选，旧 openai-llm 等调用 ID 继续解析到默认候选。“管理候选连接”支持添加独立连接，设置稳定 ID、名称及项目授权。保存产生不可变版本，排队任务保留原版本。禁用或撤销项目授权会阻止尚未提交的任务使用它。

连接测试检查鉴权、模型列表或工作流结构，生成能力由实际任务验证。私网 URL 须明确启用私网访问。密钥在服务端加密保存，界面不会回传已有密钥，工程包不包含密钥。

## 项目策略

项目所有者在“任务队列 → 模型路由策略”按用途设置政策。编辑者可生成，所有者可更改政策。没有项目政策时沿用工作室默认模型，入口也可显式选择连接。

| 策略 | 排序规则（从左到右） |
| --- | --- |
| 优先指定连接 | 指定连接顺序、优先级、费用、稳定 ID |
| 预估费用最低 | 费用、优先级、质量、延迟、稳定 ID |
| 质量优先 | 质量、优先级、费用、延迟、稳定 ID |
| 质量与延迟约束下排序 | 优先级、费用、质量、延迟、稳定 ID |

资格检查先于排序：能力、启用状态、项目授权、健康、参考图角色、转写时间戳、质量门槛、延迟、费用上限及剩余预算。优先级越小越优先，费用升序、质量降序、延迟升序，已知观测排在未知前。候选范围留空表示所有获授权的候选。手动指定也须通过检查。

质量和延迟须填写人工或测评来源。系统不推测质量、速度或价格。缺少质量和延迟时默认允许参与，也可排除。未知费用继承项目预算政策，或在路由中显式排除。币种须与项目一致，不自动换汇。

预览显示选择、版本、估价及排除理由，不调用模型、不预留费用。生成入口创建预览并在提交时重新校验，在项目事务内原子预留。批量视频按镜头数估算。任务详情“请求与溯源”显示固定路由，素材来源保存路由摘要。

## 失败与重试

可选备用切换只发生在远端提交前，范围及版本由预览固定，估价不得高于原候选。任务费用和预算账本一起更新。记录提交意图后，或结果不确定时，保留路由及费用义务，使用任务中的人工对账/恢复入口。

规划、视频、辅助素材和 VLM 审片界面保留未确认请求身份、原始影片版本及预览。网络断开后重试沿用原请求；审片 ID 同时固定整批镜头。明确的版本冲突或过期预览要求重新发起。候选配置读取、版本复核及预留与设置写入串行，不能将已批准预览改绑到新版本。审批和素材变更仍经过 Project Engine。

开发验收使用离线 Mock 和本机 HTTP 契约，没有使用真实凭据或收费服务。真实服务的兼容性、质量及账单须部署方验收。Docker / 跨运行环境验收按用户要求暂缓。
